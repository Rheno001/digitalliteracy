💡 Implementation Hints
1
Use Semantic HTML

Structure your document using tags like <header>, <main>, <section>, and <footer> instead of just using generic <div> tags everywhere.

2
Flexbox is Your Friend

Use display: flex; on the header to align the logo to the left and navigation links to the right (justify-content: space-between;). Also, use flexbox to center your hero content vertically and horizontally.

3
Reset Default Margins

Browsers add default margins to elements. Use a CSS reset at the top of your styles: * { margin: 0; padding: 0; box-sizing: border-box; } to have full control.

4
Add Interactive Hover States

Make your navigation links and buttons feel alive! Use the :hover pseudo-class to change background colors or add a subtle transition (transition: all 0.3s ease;).

5
Add Images & a Contact Form

Your portfolio must include at least two images (e.g., a profile picture and a project screenshot) and a functional-looking contact form (with inputs for name, email, and a message textarea).
